# reports

計畫書網頁「測試結果」分頁的資料來源。這個分頁用來在週會報告，只放實驗結果：模型比較、準確度、效能與選型結論。`memrag report` 完成前，這些檔案和網頁內容都手動維護。

## 這個資料夾的檔案

| 名稱 | 類型 | 說明 | 產生方式 | 進版控 |
|---|---|---|---|---|
| `README.md` | 檔案 | 本文件：說明這個資料夾的內容 | 手動維護 | 是 |
| `overview.json` | 檔案 | 分頁「總覽」的內容：目前結論、本期重點、模型比較總表、下一步與任務進度 | 手動維護，每次有新的實驗結果就更新 | 是 |
| `selection_summary.json` | 檔案 | 分頁「Embedding 模型選型總結」的內容：週報用，依序是結論、實驗方法、指標、各項結果與圖表、選型、實際流程確認、限制 | 手動維護，選型結論或主要數字改變時更新 | 是 |
| `records/` | 資料夾 | 實驗結果，一次實驗一個檔，會放上網頁，說明見 [`records/README.md`](records/README.md) | — | 是 |
| `log/` | 資料夾 | 2026-11-07 以前的過程紀錄存檔，不放上網頁，說明見 [`log/README.md`](log/README.md) | — | 是 |
