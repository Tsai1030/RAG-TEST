# 標註指南：測試問題 → Gold Fact

這份指南給標註者使用。目的是為每一題測試問題，標出哪些 Gold Fact 是機器人該找出來的記憶，用來評估 Embedding 模型的檢索準確度。

## 情境

- 陪伴機器人每天和一位使用者聊天，並把對話整理成記憶。
- 測試問題是**使用者在 2026-11-01（星期日）對機器人說的話**，也可能是機器人內部為了回應而提出的查詢。
- 機器人一定知道在跟誰說話，所以**只看同一位使用者的 Gold Fact**。其他人的事實一律是 0 分，不需要標。
- 所有人物、事件都是虛構的。

## 分數

| 分數 | 意義 | 判斷方式 |
|---|---|---|
| **2** | 直接回答 | 機器人只看這筆就能正確回應這句話 |
| **1** | 部分相關 | 和問題問的**同一件事**有關，但不足以回答；見下面的清單 |
| **0** | 不相關 | 不用標；沒列出的配對都視為 0 |

**1 分只給這幾種（2026-11-07 依第二次標註的分歧修訂）**

| 可以給 1 分 | 例：問題「膝の手術はいつ？」 |
|---|---|
| 同一件事的舊版本（被 `supersedes` 取代） | — |
| 對同一件事的感受 | 手術が怖いと話していた |
| 同一件事的其他步驟（申請→結果、練習→比賽、訂房→旅行） | 手術のために入院する |
| 問題問的治療或檢查所針對的狀況 | 膝の軟骨がすり減っている |
| 只回答一部分 | — |

**不給分（0 分）：** 只說明某人是誰的事實（「村上さんは漁師仲間」）、一般的興趣或習慣（「釣りが好き」「ゲームが好き」）、只是原因或背景的習慣（「健康のために歩いて通勤」）。這些和主題相關，但機器人用不上。

**判斷原則**

1. **先想機器人要怎麼回應這句話，再看哪些記憶用得上。** 用得上而且足夠 → 2；是同一件事但不夠 → 1；只是同主題的背景 → 0。
2. **只看意思，不看字面。** 問題和事實用不同說法、漢字或假名、敬語或口語，都不影響分數。
3. **一題可以有多筆 2 分。** 例如問「最近、体のことで何か言ってた？」，每筆健康相關事實都可能是 2。
4. **更新過的事實：** 事實有 `supersedes` 時，表示新的事實取代了舊的。
   - 問「現在」的狀況：新事實 2、舊事實 1。
   - 問「以前」或變化：兩筆都可能是 2。
5. **日期與時間：** 問題提到的時間要以 2026-11-01 為基準換算，例如「先週」是 10/25–10/31，「来週」是 11/2–11/8。只符合主題、不符合時間的事實最多 1 分。
6. **有過濾條件的題目：** 題目若標了 `filters`（日期範圍或 `category`），只能標通過過濾的事實；不通過的一律 0。
7. **無答案題：** 不標任何事實。若覺得某題其實有答案，在備註寫出來，不要硬標。

## 問題類型

這是出題時的設計，供標註者參考，不影響分數判斷。

| 類型 | 說明 | 例 |
|---|---|---|
| `direct` | 直接問某件事，用詞接近事實 | 孫の結衣ちゃんはいつ来るの？ |
| `paraphrase` | 換句話說，用詞和事實不同 | 今度、家族が遊びに来る日っていつだっけ？ |
| `notation` | 表記或語體不同：漢字／假名／片假名、敬語／口語、縮寫 | まごがくるのっていつ？ |
| `person` | 別的使用者也有相似的事實；只有本人的才算 | （其他人也有孫來訪的事實） |
| `time_category` | 帶日期範圍或類別條件 | 先週あった出来事を教えて（date 10/25–10/31） |
| `no_answer` | 本人沒有相關記憶，可能別人有 | 犬の散歩って何時だっけ？（本人沒養狗） |

## 標註檔格式

一行一筆 JSON，只列分數 1 或 2 的配對：

```json
{"query_id": "q_p01_01", "fact_id": "f_p01_03", "grade": 2, "annotator": "claude-1"}
```

## 第二次標註（D7）

- 由另一個 Claude 工作階段進行，只看這份指南、人物設定、Gold Facts 與問題，**不看第一次的標註**。
- 抽樣至少 20% 的題目，依問題類型分層抽出，清單在 `data/00_gold/second_pass_sample.json`。
- 用 `memrag dataset agreement` 計算 Cohen's κ：同一使用者的每一個（問題, 事實）配對都算一個項目，沒列出的配對視為 0。
- 分歧依這份指南裁決，理由寫進 `docs/annotation_review.md`；指南不清楚的地方要修改指南。

## 限制

兩次標註都由 Claude 進行，且 Claude 不是日文母語者，κ 可能偏高，只能當指南是否清楚的參考。日後能找到日文母語者時，再抽查一部分題目。
