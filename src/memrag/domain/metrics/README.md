# domain/metrics

指標與統計的純函式，只用 Python 標準函式庫，以手算案例驗證。

## 這個資料夾的檔案

| 名稱 | 類型 | 說明 | 產生方式 | 進版控 |
|---|---|---|---|---|
| `README.md` | 檔案 | 本文件：說明這個資料夾的內容 | 手動維護 | 是 |
| `__init__.py` | 檔案 | 套件標記，內容為空 | 手動維護 | 是 |
| `statistics.py` | 檔案 | Cohen's κ、Bootstrap 與配對 Bootstrap 95% 信賴區間、AUC | 手動維護 | 是 |
| `retrieval.py` | 檔案 | 單一 Query 的 Recall@k、MRR@k、nDCG@k（分級標註，增益等於分數） | 手動維護 | 是 |
