# domain/schemas

資料結構定義。記憶、對話、檢索、評估的 Schema 會在 5.1.3 之後加入。

## 這個資料夾的檔案

| 名稱 | 類型 | 說明 | 產生方式 | 進版控 |
|---|---|---|---|---|
| `README.md` | 檔案 | 本文件：說明這個資料夾的內容 | 手動維護 | 是 |
| `__init__.py` | 檔案 | 套件標記，內容為空 | 手動維護 | 是 |
| `embedding.py` | 檔案 | `ModelSpec`（`models.yaml` 的一筆）、`EncodedText`（實際送進模型的文字）與 prefix 規則 | 手動維護 | 是 |
