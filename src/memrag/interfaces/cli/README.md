# interfaces/cli

`memrag` 指令。所有指令都支援 `--json`；錯誤訊息會標出是哪個指令出錯，並以結束碼 2 結束。

## 這個資料夾的檔案

| 名稱 | 類型 | 說明 | 產生方式 | 進版控 |
|---|---|---|---|---|
| `README.md` | 檔案 | 本文件：說明這個資料夾的內容 | 手動維護 | 是 |
| `__init__.py` | 檔案 | 套件標記，內容為空 | 手動維護 | 是 |
| `main.py` | 檔案 | 指令入口：註冊子指令、統一處理錯誤 | 手動維護 | 是 |
| `commands/` | 資料夾 | 各子指令，說明見 [`commands/README.md`](commands/README.md) | — | 是 |
